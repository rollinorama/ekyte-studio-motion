# Referências

Os vídeos aprovados que são o padrão de qualidade. Poucos e bons: uma referência por formato para começar.

Uma pasta por vídeo, por exemplo `reference/ia-gerar-tarefas/`:

| Arquivo | Para quê |
| --- | --- |
| `roteiro.md` | Roteiro com cenas e tempos |
| `contact-sheet.png` | Um frame por beat: é como o Claude "vê" o resultado |
| `source/` | `index.html` + `beats.json` do vídeo aprovado: mostra como as cenas foram construídas |
| `video.mp4` ou `link.md` | O vídeo final, para o time assistir |
| `notas.md` | Opcional: 2 ou 3 linhas sobre por que ele é referência |
